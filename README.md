# 🌷 Un jardín para una sonrisa

Una mini web floral, animada y adaptable a celulares. No menciona el nombre de la destinataria y funciona sin framework, compilación ni instalación.

## Publicarla gratis con GitHub Pages

1. En GitHub crea un repositorio nuevo, por ejemplo `jardin-de-flores`.
2. Sube el archivo `index.html` **a la raíz del repositorio** (no es necesario subir el README).
3. Abre el repositorio → **Settings** → **Pages**.
4. En *Build and deployment*, elige **Deploy from a branch**; selecciona la rama `main` y la carpeta `/ (root)`; guarda.
5. En la misma página aparecerá la dirección cuando esté publicada. Generalmente tendrá la forma `https://TU-USUARIO.github.io/jardin-de-flores/`.

## Incluye

- Ramo de flores SVG animado al entrar.
- Jardín táctil con 9 flores y mensajes diferentes.
- Pétalos flotantes y pequeños efectos al tocar flores.
- Cambio de tema entre día y noche.
- Tres tarjetas de detalles bonitos.
- Sobre animado que se abre para revelar una nota.
- Botón para compartir el enlace.
- Diseño responsivo para celulares, tabletas y computadora.
- Soporte para reducir movimiento y navegación con teclado.

## Personalizar textos

Abre `index.html` en VS Code. Busca `Hay sonrisas` para editar la portada; `const messages` para editar las nueve frases de las flores; y `Para una sonrisa especial` para editar la nota. Todo el CSS y JavaScript están incluidos en el mismo archivo.

**Nota:** Google Fonts requiere conexión a internet, pero si no está disponible la página utiliza tipografías locales.
